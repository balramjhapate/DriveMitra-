# 08_SEO_Blueprint.md

# Purpose

This document defines the complete SEO strategy for the Bhopal Car Rental platform.

The objective is NOT only ranking.

The objective is to create a website that performs well for

- Google Ads
- Organic SEO
- AI Search
- Google AI Overview
- Bing AI
- ChatGPT Search
- Perplexity
- Voice Search
- Local Search

while maintaining excellent User Experience.

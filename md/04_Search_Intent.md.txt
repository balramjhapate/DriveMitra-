# 04_Search_Intent.md

# Purpose

This document defines the complete Search Intent Architecture for the project.

Everything in this project must start from **Search Intent**, not from design.

The Landing Page, Google Ads, Meta Ads, SEO, Copywriting and Future City Pages will all be built around user intent.

If Search Intent is wrong,

everything becomes expensive.

Higher CPC.

Lower Quality Score.

Lower Conversion.

Poor SEO.

---

# Search Intent Philosophy

People never search because they want a website.

People search because they have a problem.

Our job is to solve that problem faster than competitors.

Therefore

Search

↓

Intent

↓

Solution

↓

Landing Page

↓

Lead

↓

Booking

Never reverse this flow.

Never run ads first.

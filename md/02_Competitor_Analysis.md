# 02_Competitor_Analysis

# Objective

Reverse engineer the Bhopal car rental market to build a landing page
that outperforms competitors in UX, trust, SEO and conversions.

# Primary Competitors (Public Research)

-   MyTrip Self Drive
-   Veecar Self Drive
-   MI Travels
-   Drive Urself
-   U Drive
-   GoOnDrive
-   Friends Car Services
-   FS Car Rental

# Analysis Framework

For every competitor evaluate: - Homepage - Hero section - Navigation -
Booking flow - CTA placement - WhatsApp visibility - Phone CTA - Fleet
showcase - Pricing visibility - FAQ - Reviews - Trust badges - Footer -
Mobile UX - Page speed (future validation)

# Market Observations

## Strengths

-   Strong Google Maps visibility
-   Local trust
-   Phone-first sales
-   WhatsApp support
-   Known local brands

## Weaknesses

-   Generic layouts
-   Weak branding
-   Inconsistent UI
-   Limited animations
-   Low emotional storytelling
-   Basic forms
-   Limited CRO

# Opportunities

-   Premium modern interface
-   Mobile-first experience
-   Sticky CTAs
-   Better trust section
-   Faster booking flow
-   Better copywriting
-   Rich FAQ
-   Better SEO structure

# Design Goals

Look like a premium travel-tech startup instead of a traditional rental
website.

# Temporary Public Findings

Publicly visible pricing and policies should be treated as reference
only until field verification.

# 05_Landing_Page_Architecture.md

# Purpose

This document is the **Master Product Requirement Document (PRD)** for the landing page.

This is **NOT** a UI mockup.

This is **NOT** a wireframe.

This is the implementation blueprint that AI coding agents (Antigravity, Claude Code, Cursor, Windsurf, Codex, etc.) and React developers should follow to build the website.

Every design decision, component, animation, spacing, CTA, SEO element, and conversion optimization must follow this document.

# Antigravity Instructions

Build each section as an independent reusable block.

Never hardcode spacing.

Use global design tokens.

Every section must support future reuse on city-specific pages.

Every component must accept props.

All cards must be reusable.

No duplicated code.

Keep animations subtle.

Optimize for Core Web Vitals.

Use Server Components by default.

Client Components only where interaction is required.

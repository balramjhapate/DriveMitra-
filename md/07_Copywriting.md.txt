# 07_Copywriting.md

# Purpose

This document defines the complete copywriting strategy for the entire website.

The objective is NOT to write beautiful content.

The objective is to maximize:

- Google Ads Quality Score
- Conversion Rate
- User Trust
- Average Session Duration
- Lead Generation
- Organic SEO Readability

This copywriting system should work for:

- Google Ads Traffic
- Organic Search
- Direct Traffic
- WhatsApp Traffic
- Facebook Ads
- Instagram Ads
- Future SEO Landing Pages

---

# Copywriting Philosophy

Never write like a local business.

Never write like AI.

Never write like a salesman.

Write like a premium travel-tech company.

Tone should feel

Professional

Trustworthy

Friendly

Helpful

Modern

Premium

Simple

Human

---

# Writing Rules

Every section should answer

Why should I trust you?

Why should I book today?

Why should I choose you instead of others?

How fast can I book?

Will this process be easy?

---

# Tone of Voice

Avoid

❌ Cheap Marketing

❌ Fake Urgency

❌ Fake Reviews

❌ Clickbait

❌ Keyword Stuffing

❌ ALL CAPS

❌ Overpromising

Use

✅ Honest

✅ Helpful

✅ Clear

✅ Short Sentences

✅ Natural Language

# SEO Copywriting Rules

One H1 only.

Natural keyword placement.

Never force keywords.

Every section should answer one search intent.

Use conversational language.

Avoid repetitive sentences.

Maintain semantic relevance.

Write for humans first and search engines second.

---

# Google Ads Copywriting Rules

Headline should match landing page H1.

CTA should remain consistent.

Message match should be maintained.

Benefits before features.

Trust before pricing.

Clear action above the fold.

---

# Copywriting Quality Checklist

✓ Human sounding

✓ Mobile readable

✓ Premium tone

✓ No keyword stuffing

✓ Trust focused

✓ Benefit driven

✓ CTA every major section

✓ Easy to skim

✓ Short paragraphs

✓ SEO friendly

✓ Conversion focused

# 00_Project_Overview

## Project Name

**Working Name:** DriveMitra (Temporary)

**Version:** 1.0

**Status:** Research & Production Planning

------------------------------------------------------------------------

# Project Vision

Build a premium, modern, conversion-focused car rental platform for
Bhopal that is designed for:

-   Google Ads first
-   SEO second
-   Mobile-first UX
-   Maximum lead generation
-   Future multi-city expansion
-   Future fleet ownership
-   React / Next.js production

This documentation is written so an AI coding agent or developer can
build the project without additional explanations.

------------------------------------------------------------------------

# Primary Objectives

-   Highest Google Ads Quality Score
-   Lowest Cost Per Click (CPC)
-   Lowest Cost Per Lead (CPL)
-   Highest Conversion Rate
-   Premium Brand Perception
-   Fast Website
-   Mobile First Experience

------------------------------------------------------------------------

# Business Model

Customer → Google Search / Meta Ads → Landing Page → Lead Form /
WhatsApp / Call → Booking Team → Rental Partner → Customer

Future: Rental Partner + Own Fleet + Multi-city Expansion

------------------------------------------------------------------------

# Landing Page Principles

-   Premium look
-   Human-designed feel
-   Never appear AI-generated
-   Strong trust signals above the fold
-   Instant lead capture
-   Mobile-first
-   Fast loading
-   SEO-ready

------------------------------------------------------------------------

# Hero Section

Must contain:

-   Visible booking form
-   Call button
-   WhatsApp button
-   Trust badges
-   Customer ratings
-   Primary CTA
-   Secondary CTA
-   Premium hero image

No popup. Form must be visible on initial load.
